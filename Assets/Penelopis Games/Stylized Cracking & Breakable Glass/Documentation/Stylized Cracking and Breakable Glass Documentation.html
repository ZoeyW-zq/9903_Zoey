Overview

Stylized Cracking & Breakable Glass contains two configured breakable glass prefabs for Unity.

  1. Tall Stylized Breakable Glass: a large multi-stage panel. The first impact breaks the panel into larger chunks. Each chunk can then crack and shatter into smaller pieces.
  2. Short Stylized Breakable Glass: a smaller panel. The first impact shows cracks, and the second impact shatters it.

The package also includes a ready-to-use demo scene with a capsule controller for quick testing.

Quick Start

  1. Open Assets/Penelopis Games/Stylized Cracking & Breakable Glass/Scenes/Penelopis Games Asset Store.unity.
  2. Press Play.
  3. Move the capsule with W, A, S, D. Press Space to jump.
  4. Push the capsule into a glass panel.
  5. Test the intended behavior: short glass cracks first and shatters second; tall glass breaks into larger chunks first, then individual chunks crack and shatter.

  • StylizedGlassDemoController removes PlayerHeartsCanvas at runtime if another gameplay system creates it.

Collision Requirements

For glass to react to an impact:

  1. The hitting object must have a Collider.
  2. Either the glass setup or the hitting object must have a Rigidbody.
  3. The collision speed must be at least Min Impact Speed.
  4. The hitting object must be on a layer included in Impact Mask.

The included demo capsule is on the Props layer. The included glass prefabs accept impacts from Enemy, EnemyRagdoll, and Props.

StylizedBreakableGlass Component

StylizedBreakableGlass is the runtime component used by the included prefabs.

It supports impact filtering by layer, minimum impact speed, crack stage before shatter, shattering by speed/damage/hit count, preplaced shard roots, optional spawned shattered prefabs, optional VFX, direct AudioClip playback, shard physics impulses, shard lifetime cleanup, and shard freezing/disabling/destruction.

Impact Fields

FieldTypeDescription
Impact MaskLayerMaskLayers allowed to damage or break the glass. Impacts from all other layers are ignored.
Min Impact SpeedfloatMinimum collision speed required before an impact is accepted. Below this value, no crack, shatter, spark, sound, or noise event is triggered.
Shatter Impact SpeedfloatSpeed threshold for immediate shatter when Allow Instant Shatter By Speed is enabled.
Allow Instant Shatter By SpeedboolWhen enabled, a hit at or above Shatter Impact Speed shatters immediately regardless of damage or hit count. The included prefabs keep this disabled for predictable staged behavior.
Impact CooldownfloatMinimum time in seconds between accepted impacts. Increase it if one physical hit counts multiple times.
Damage Per SpeedfloatAdditional damage based on speed above Min Impact Speed. Formula: Flat Damage Per Hit + max(0, speed - Min Impact Speed) * Damage Per Speed.
Flat Damage Per HitfloatDamage added for every accepted hit regardless of speed.
Damage To ShatterfloatAccumulated damage required to shatter. Use a high value when hit count should control shattering.
Hits To ShatterintAccepted hit count required to shatter. 1 shatters on first hit. 2 cracks first and shatters second.

Cracked Stage Fields

FieldTypeDescription
Cracked VisualGameObjectOptional visual object shown when the glass enters its cracked stage. It is hidden during startup and enabled on the first accepted hit.
Cracked Visual Replaces IntactboolWhen enabled, intact renderers are hidden when the cracked visual appears. Use this for a full replacement cracked mesh. Disable it for overlay-only crack lines.

For pre-fractured setups, Cracked Visual may be inside Preplaced Shards Root. The script activates the shard root when needed so the cracked visual can become visible.

Shard Fields

FieldTypeDescription
Shattered PrefabGameObjectOptional prefab spawned at shatter time if Preplaced Shards Root is not assigned.
Preplaced Shards RootTransformTransform containing prebuilt shard objects. At startup the script caches shard rigidbodies, colliders, and renderers, then hides/deactivates them. At shatter time it activates the root, enables shards, and optionally applies physics.
Detach Shards On ShatterboolDetaches the shard root from the glass object during shatter so shards can simulate independently.
Activate Shard Physics On ShatterboolWhen enabled, shard rigidbodies become non-kinematic and receive impulses. When disabled, shards become visible but stay kinematic. This is useful for the tall glass first stage.
Shard Impulse MultiplierfloatStrength of the shatter impulse. Higher values send pieces farther. Zero means no impulse.
Shard Up BiasfloatAdds upward force to shard impulse direction.
Random Impulse JitterfloatAdds random variation to shard impulse directions.
Shard Max Angular VelocityfloatSets Rigidbody.maxAngularVelocity for shards, controlling maximum spin speed.
Shatter VFX PrefabGameObjectOptional visual effect prefab spawned at the impact point when shatter occurs.

Impact VFX Fields

FieldTypeDescription
Hit Spark PrefabGameObjectOptional visual effect spawned on every accepted impact.
Hit Spark ScalefloatScale multiplier applied to the hit spark instance.
Hit Spark World OffsetVector3World-space offset added to the spark spawn position.
Hit Spark Normal OffsetfloatOffset applied along the contact normal to avoid z-fighting or spawning inside the glass.

After Shatter Fields

FieldTypeDescription
Shard LifetimefloatDelay in seconds before shard cleanup behavior starts. If set to 0 or less, cleanup is skipped.
Shard End ModeenumFreeze stops shards and makes them kinematic. Disable disables the shard root. Destroy destroys the shard root.

Using The Prefabs In Your Own Scene

  1. Drag Tall Stylized Breakable Glass or Short Stylized Breakable Glass into your scene.
  2. Place it at the desired position.
  3. Make sure the object that hits it has a Collider and participates in Rigidbody collision.
  4. Put the hitting object on a layer included in the glass Impact Mask.
  5. Press Play and test collisions at a speed above Min Impact Speed.

Common Customization Recipes

Make glass harder to crack

  • Increase Min Impact Speed.
  • Increase Hits To Shatter.
  • Increase Damage To Shatter.

Make glass break immediately

  • Set Hits To Shatter to 1.
  • Or enable Allow Instant Shatter By Speed and set Shatter Impact Speed.

Make shards fly farther

  • Increase Shard Impulse Multiplier.
  • Increase Shard Up Bias.
  • Increase Random Impulse Jitter.

Make shards stay close

  • Decrease Shard Impulse Multiplier.
  • Decrease Random Impulse Jitter.

Make shards disappear after breaking

  • Set Shard End Mode to Disable or Destroy.
  • Set Shard Lifetime.

Make cracked glass replace the intact mesh

  • Assign Cracked Visual.
  • Enable Cracked Visual Replaces Intact.

Troubleshooting

Glass does not react at all

  • Put the hitting object on a layer included in Impact Mask.
  • Add Rigidbody to the hitting object or the glass setup.
  • Make sure colliders are enabled and not incorrectly marked as triggers.
  • Increase collision speed or lower Min Impact Speed.

Glass cracks but never shatters

  • Lower Hits To Shatter.
  • Lower Damage To Shatter.
  • Enable Allow Instant Shatter By Speed and lower Shatter Impact Speed.

Glass shatters immediately

  • Increase Hits To Shatter.
  • Disable Allow Instant Shatter By Speed.
  • Increase Shatter Impact Speed or Damage To Shatter.

Cracked visual does not appear

  • Assign Cracked Visual.
  • Ensure the cracked visual has active Renderer components.
  • If Cracked Visual is inside Preplaced Shards Root, make sure that root is assigned.

Shards appear but do not move

  • Enable Activate Shard Physics On Shatter.
  • Make sure shard objects have Rigidbody components.
  • Increase Shard Impulse Multiplier.

Gameplay UI appears in the demo scene

  • The included demo controller removes PlayerHeartsCanvas at runtime.
  • Delete any unrelated gameplay UI object from the demo scene if it was added manually.
